# 随身翻译

在线使用：[随身翻译](https://9serendipity.github.io/translate/)

本仓库根目录就是网站内容，通过 GitHub Pages 从 `main` 分支发布。

听一种语言，翻成另一种语言，完整原文和译文按时间留在主页面。中间的交换按钮一键对调方向。

点一下麦克风就出字幕。iPhone 用 Safari 打开 → 分享 → **添加到主屏幕**，就是个全屏 App。

> iOS 不允许网页抓取别的 App 播放的声音，所以只能靠**麦克风**收音，
> 不能像桌面版那样直接监听系统声音。把手机放在说话人附近就行。

## 用法

- 麦克风按钮点一下开始听，再点一下停止；停止后会处理最后一段，长时间没有输入会自动收麦
- ⇄ 对调方向（英译中 ⇄ 中译英），左下是「说」的语言，右下是「译成」的语言
- 点左右两个语言名可换语言（17 种）
- ⌨ 麦克风不行时打字也能翻
- 主页面向上滑动可回看完整对话，回看时新译文不会把页面拉到底；点「回到最新」可继续跟随
- ☰ 记录与导出，可复制或导出 SRT
- ⚙ 语音识别 / 硅基流动 Key / 字号（22–64px）/ 翻译引擎 / 自定义翻译 API
- 右下角波形按钮 / 设置中的「收音测试」：录 10 秒、看音量并回放，可对比人声模式与环境模式

语音识别默认选硅基流动 SenseVoiceSmall，需在设置里填写自己的硅基流动 API Key；也可以切回免 Key 的系统语音识别。
翻译默认走 Google，连不上自动退 MyMemory，
也可以选择「硅基流动 · DeepSeek Flash」，或填写自己的 DeepSeek / OpenAI 兼容接口。

请把手机靠近说话人或另一台设备的外放音源，左侧语言必须与说话语言一致。
系统识别使用 Safari 语音引擎；硅基流动模式由网页录音并请求浏览器启用自动音量、降噪和回声消除，设备可能忽略设置。
如果系统识别不返回文字，可点左下角键盘按钮，使用 iPhone 键盘的听写后再翻译。

## 收音测试与翻译流程

### 硅基流动 AI 识别

1. 在 [硅基流动控制台](https://cloud.siliconflow.cn/) 注册，按平台要求完成实名认证，在「API 密钥」中创建 Key。
2. 本页设置中选择「硅基流动 AI」，填写该 Key；可勾选「在这台手机记住 Key」。默认只保存在当前会话。
3. 点说话后音频直接传给硅基流动；本页不持久保存音频，完整原文和译文沿用本机对话记录。

固定使用 `FunAudioLLM/SenseVoiceSmall`，按 [官方当前价格](https://www.siliconflow.cn/pricing) 免费，受账户限速限制。使用要求与限额以 [平台说明](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation) 为准。
SenseVoiceSmall 支持普通话、粤语、英语、日语和韩语，接口自动识别所说语言。左侧仍须选实际说话语言，供后续翻译使用；其他语言请切换系统识别。

网页采集单声道音频并生成 16 kHz WAV，温和放大偏小音量；停顿约 0.65 秒时尽快提交，连续讲话约每 8 秒切一段。识别与网络仍有耗时，并非逐字流式识别。
当前页面顺序发送请求，最小间隔 1.2 秒；Key 无效、限速或连接失败时停止收音并提示，不自动反复重试。更换语言、输入打字、开始收音测试或切后台会取消未完成的识别。
录音期间暂停自动朗读，避免回声。停止按钮会等待最后一段采样和识别完成。

Key 只发送到固定的 `api.siliconflow.cn`；旧版其他供应商的 Key 不会用于此接口，已有对话记录会保留。语音识别 Key 与自定义翻译 Key 分别配置。

### 硅基流动 DeepSeek 翻译

设置 → 翻译引擎 →「硅基流动 · DeepSeek Flash」，填写自己的「硅基流动翻译 API Key」后点完成。可以填写与语音识别相同的硅基流动 Key，两处分别配置。

翻译使用 `https://api.siliconflow.cn/v1/chat/completions`，模型为 `deepseek-ai/DeepSeek-V4.1-Flash`，关闭思考模式。根据 [官方升级公告](https://api-docs.siliconflow.cn/docs/release-notes/overview)，该模型 ID 当前由 1017 版提供服务，模型 ID 保持不变。

翻译 Key 默认只保存在当前会话；勾选「在这台手机记住翻译 Key」后才存到当前浏览器本地。Key 和原文直接发给硅基流动，翻译按模型输入和输出用量计费，以 [平台价格](https://www.siliconflow.cn/pricing) 为准。选择该引擎时不会自动转发给其他翻译服务；接口无效、余额不足和限流会明确提示。

### 系统识别与独立测试

测试录音只保留在当前页面内存中，不会上传；开始测试会先停止系统听写，关闭测试、切后台或录满 10 秒后释放麦克风。
两种录音模式只是向浏览器请求不同的音频处理设置，设备可能忽略；面板显示设备实际报告的设置。
这与 Safari 系统听写可能采用不同的处理，不能把测试音量当作识别质量的结论，需回放听清晰度。

识别中的原文会单独实时显示；一旦临时结果出现句末标点，就立即送去翻译，不必等浏览器确认整段结束。
没有标点的连续讲话，会取连续两次识别都稳定的前缀，按短段提前翻译；剩余内容继续识别。提前分段的译文会进入主页面并标记「实时」，确认后在同一条记录更新；尚不完整的短句预览只在当前翻译区域显示。
浏览器随后确认同一句时，复用已完成或仍在请求中的结果，避免重复翻译和字幕倒退；更换语言或输入新文字会取消过时请求，超时请求会真正中止。
这是提前分段策略，句界与临时识别文字仍可能被浏览器修正；翻译接口和网络仍有耗时。
MyMemory 长文本按 UTF-8 字节切分，避免中文超限；收音期间暂停自动朗读，避免扬声器回声被再次识别。

主页面不裁切原文或译文，长内容通过页面中的对话区域滚动查看。最近 1000 条记录保存在当前浏览器本地，旧版已有记录会继续显示。
手机布局跟随可用屏幕高度变化，并为 iPhone 顶部与底部安全区域留出空间。
