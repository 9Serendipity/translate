# 随身翻译

在线使用：[随身翻译](https://9serendipity.github.io/translate/)

本仓库根目录就是网站内容，通过 GitHub Pages 从 `main` 分支发布。

一个页面，一块大字：听一种语言，翻成另一种语言。中间的交换按钮一键对调方向。

点一下麦克风就出字幕。iPhone 用 Safari 打开 → 分享 → **添加到主屏幕**，就是个全屏 App。

> iOS 不允许网页抓取别的 App 播放的声音，所以只能靠**麦克风**收音，
> 不能像桌面版那样直接监听系统声音。把手机放在说话人附近就行。

## 用法

- 麦克风按钮点一下开始听，再点一下停止；停止后会等最后一句识别完成，30 秒没有新结果自动收麦
- ⇄ 对调方向（英译中 ⇄ 中译英），左下是「说」的语言，右下是「译成」的语言
- 点左右两个语言名可换语言（17 种）
- ⌨ 麦克风不行时打字也能翻
- ☰ 记录，可导出 SRT
- ⚙ 字号（22–64px）/ 翻译引擎 / 自定义 API key
- 右下角波形按钮 / 设置中的「收音测试」：录 10 秒、看音量并回放，可对比人声模式与环境模式

语音识别用 Safari 自带的 Web Speech API（需联网）；翻译默认走 Google，连不上自动退 MyMemory，
也可以在设置里填自己的 DeepSeek / OpenAI key 换更高质量。

请把手机靠近说话人或另一台设备的外放音源，左侧语言必须与说话语言一致。
Safari 的语音识别使用系统语音引擎，本网页没有调整麦克风增益的开关。
如果系统识别不返回文字，可点左下角键盘按钮，使用 iPhone 键盘的听写后再翻译。

## 收音测试与翻译流程

测试录音只保留在当前页面内存中，不会上传；开始测试会先停止系统听写，关闭测试、切后台或录满 10 秒后释放麦克风。
两种录音模式只是向浏览器请求不同的音频处理设置，设备可能忽略；面板显示设备实际报告的设置。
这与 Safari 系统听写可能采用不同的处理，不能把测试音量当作识别质量的结论，需回放听清晰度。

识别中的原文会单独实时显示；确认的句子依次翻译、记录，只处理新句子。
连续说话也会限频预览译文，临时结果不会进入记录。更换语言或输入新文字会取消过时请求；超时的请求会真正中止。
MyMemory 长文本按 UTF-8 字节切分，避免中文超限；收音期间暂停自动朗读，避免扬声器回声被再次识别。
